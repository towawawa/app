プライバシーポリシー

最終更新日: 2026年10月25日

1. はじめに

本プライバシーポリシーは、「Hookline」アプリケーション（ウィジェットと共有メニューの機能を含みます。以下「本アプリ」）における、ユーザー情報の取り扱いについて説明するものです。

2. 開発者が収集する情報

本アプリにアカウント登録の機能はなく、開発者が氏名・メールアドレスなどの個人情報を収集することはありません。

3. 端末内に保存する情報

動画のタイトル・メモ・台本・撮影するカット・投稿予定日・投稿先・投稿した動画の URL・キャプション・再生数などの実績、保存したハッシュタグ、各種の設定は、ユーザーの端末内にのみ保存されます。ホーム画面のウィジェットと共有メニューは、同じ端末内のデータを読み書きします。これらの情報が開発者のサーバーに送信されることはありません（次の「YouTube API サービスの利用」で説明する、YouTube の動画 ID の問い合わせを除きます）。

4. YouTube API サービスの利用

本アプリ（バージョン 1.1 以降）は、YouTube の公開動画の再生数・高評価数・コメント数を取り込むために、YouTube API サービスを利用しています。本アプリで YouTube からの取り込みを使うことにより、ユーザーは YouTube 利用規約（https://www.youtube.com/t/terms）に同意したものとみなされます。Google による情報の取り扱いについては、Google プライバシーポリシー（https://policies.google.com/privacy）をご確認ください。

  • 取得するもの: ユーザーが入力した URL の動画の、公開されている再生数・高評価数・コメント数だけです。ユーザーの Google アカウントや YouTube アカウントへのログインは行わず、非公開の情報やアカウントの情報には一切アクセスしません。
  • 送信するもの: 取り込みのときに、動画の ID と、回数制限のために端末ごとに作る識別子（アプリが作るランダムな ID で、個人を特定するものではありません）を、開発者が運営する中継サーバーに送ります。中継サーバーはこれを YouTube に問い合わせ、同じ動画の結果を最大1時間保存します。動画の ID と識別子を、ほかの目的に使ったり第三者に提供したりすることはありません。
  • 保存と削除: 取り込んだ数字は端末内に保存し、30日を過ぎる前に取り直します。取り直せなかった数字と、30日より前の記録は自動で削除します。動画が削除・非公開になった場合も、その動画の数字を削除します。
  • ユーザーによる削除: 本アプリの設定画面の「取り込んだ YouTube の数字を削除」から、取り込んだ数字・記録・動画の URL をいつでもすべて削除できます。投稿ごとに「取り込みをやめる」を選んでも削除できます。
  • アクセスの取り消し: 本アプリは Google アカウントへのアクセスの許可を求めないため、Google 側で取り消す操作は必要ありません。Google のセキュリティ設定ページ（https://security.google.com/settings/security/permissions）では、ほかのアプリに与えたアクセスの確認と取り消しができます。

5. 共有メニューからの保存

他のアプリやブラウザの共有メニューから本アプリにページや動画を保存すると、そのタイトルとURLを端末内に保存します。タイトルが共有されなかった場合は、ページのタイトルを取得するために、共有されたURLのページに端末から直接アクセスすることがあります。この通信は開発者のサーバーを経由しません。

6. 通知

投稿予定のお知らせと、投稿後に数字の記録をうながすお知らせは、端末内で予約するローカル通知です。通知の内容が外部に送信されることはありません。通知は本アプリの設定、または端末の設定からいつでもオフにできます。

7. 広告（Google AdMob）

本アプリの無料版では、Google LLC が提供する広告配信サービス「Google AdMob」を利用しています。AdMob は、広告の配信・効果測定のために、端末の広告識別子（IDFA）などのデバイス情報や広告の表示・操作に関する情報を収集する場合があります。広告識別子の利用は、端末の「App からのトラッキング要求を許可」などの設定に従います。

Google による情報の取り扱いについては、Google のプライバシーポリシー（https://policies.google.com/privacy）をご確認ください。Hookline Pro をご利用の場合、広告は表示されません。

8. アプリ内課金

Hookline Pro の購入・更新・解約は Apple の App Store を通じて行われます。支払い情報は Apple が管理し、開発者が取得することはありません。

9. 第三者への提供

開発者は、法令に基づく場合を除き、ユーザーの情報を第三者に提供しません。YouTube の数字の取り込みのときに、動画の ID を YouTube（Google LLC）に問い合わせることを除きます。

10. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更することがあります。重要な変更がある場合は、アプリのアップデートなどでお知らせします。

11. お問い合わせ

本ポリシーに関するご質問は、App Store のサポートページ（https://imamoto-lab.com/）からお問い合わせください。
